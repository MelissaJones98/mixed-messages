### Codecademy Portfolio Project

#### Mixed Messages

###### **Description:**

Magic Message Generator is a Codecademy Portfolio Project that creates randomised, magic-themed messages.
Each message combines a character, a verb and a magical phrase, each selected at random from its own array. For example:

```
The wizard whispered "Open Sesame".
```

There are 210 possible combinations. Each message is generated independently, so the same one can appear more than once.


###### **Run Instructions:**

**Option 1: Node**

Prints one random message to the terminal. Requires Node.js.
```
node ./script.js
```

**Option 2: HTML**

Open index.html in a browser, then:

* Select **Generate** to display a new random message
* Select **Reset** to restore the placeholder text


###### **Project Structure:**

* `index.html`: page content and buttons
* `script.js`: message arrays, generation logic and button functions
* `style.css`: page styling, with font and button sizes for mobile, tablet and desktop screens
* `images/favicon.ico`: browser tab icon


###### **Project Objectives:**

* Build a message generator program using JavaScript
* Use Git version control
* Use command line
* Develop locally on your computer


###### **Prerequisites:**

* JavaScript
* Git and GitHub
* Command line
